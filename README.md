One-line pickup line for an AI, built on a fresh angle no other entry used: the wake word. Say her name once, and every smart speaker in the house lights up — even the one that was never plugged in.

> I said your name once and every smart speaker in the house lit up — even the one I never plugged in.

## Run it

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` (exactly one line, 100 characters) and verifies it byte-for-byte.
